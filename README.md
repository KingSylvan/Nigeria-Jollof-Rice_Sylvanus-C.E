# Nigeria-Jollof-Rice
A blog site for my favorite Jollof

A simple HTML and CSS tribute to Nigerian jollof rice. The page highlights its ingredients, preparation, cultural significance, and popularity at celebrations.

## Preview

1. Open `index.html` in a web browser.
2. Make sure `style.css` is in the same folder.

## Project Files

- `index.html` — page structure and content
- `style.css` — page layout and visual styling

## Technologies

- HTML5
- CSS3
